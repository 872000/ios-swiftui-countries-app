# iOS Countries App (SwiftUI)

A SwiftUI iOS app project from my coursework — created as the starting point for a countries app.

## What's actually in here

Honestly: this is the stock Xcode SwiftUI app template. `ContentView` shows only the default "Hello, world!" view with a globe SF Symbol, and the app entry point launches it. No countries data, no lists, no networking — the countries functionality this project was named for was never implemented.

What *is* real here: a working, buildable Xcode project with the standard scaffolding — `App` entry point, preview provider, asset catalogs with app icon set, and an `.xcodeproj` targeting iOS.

## Tech stack

- SwiftUI, Xcode project targeting iOS
- Standard Xcode template structure (created December 2023)

## Build & run

Open `Parth_Countries.xcodeproj` in Xcode and run on a simulator or device.

## Project structure

```
Parth_Countries/
├── Parth_CountriesApp.swift   # @main app entry point
├── ContentView.swift          # default template view ("Hello, world!")
├── Assets.xcassets/           # app icon + accent color
└── Preview Content/           # SwiftUI preview assets
Parth_Countries.xcodeproj/
```
